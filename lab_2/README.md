# Лабораторная работа №2

Streamlit-приложение для чтения основной информации из графических файлов.

Поддерживаемые форматы:

- JPG / JPEG
- GIF
- TIF / TIFF
- BMP
- PNG
- PCX

Приложение отображает:

- имя файла;
- размер изображения в пикселях;
- разрешение DPI;
- глубину цвета;
- тип сжатия.

Для чтения графических файлов используется библиотека Pillow.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
streamlit run app.py
```
